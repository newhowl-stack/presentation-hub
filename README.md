# Presentation Hub

Static hosting structure for shareable HTML presentations.

## Current Project

- `slidesite-pitch`
- latest: `projects/slidesite-pitch/latest/`
- v1: `projects/slidesite-pitch/v1/`

## Add A New Presentation

1. Choose a project slug, e.g. `client-strategy-deck`.
2. Create `projects/client-strategy-deck/v1/index.html`.
3. Copy the approved deck into that folder.
4. Create or update `projects/client-strategy-deck/manifest.json`.
5. Add the project to root `manifest.json`.
6. Copy the approved current version to `projects/client-strategy-deck/latest/index.html`.

Keep old version folders intact after sharing.
